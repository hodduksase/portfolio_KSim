[Project 3] 신용카드 VIP 잠재 고객 예측
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

제목: 신용카드 VIP 잠재 고객 예측

부제: 계층적 분류(Hierarchical Classification)를 통한 데이터 불균형 해소 및 마케팅 효율화

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 프로젝트 배경 및 목적

Background:
상위 0.05%의 VIP 고객이 전체 매출의 80%를 차지하는 파레토 법칙이 존재하나, 
이들을 예측하고 관리하는 모델의 정확도가 낮음.

Pain Point:
VIP 고객 데이터가 매우 적은 '클래스 불균형(Class Imbalance)' 문제로 인해 
일반 모델 적용 시 예측 성능 저하.

Goal:
잠재 VIP를 정확히 식별하여 마케팅 예산 낭비를 줄이고, 충성 고객으로 전환 유도.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. 사용 기술 (Tech Stack)

Language: Python

Library: Scikit-learn, Imbalanced-learn (SMOTE), LightGBM

Method: Hierarchical Classification (계층적 분류), Under-sampling

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3. 문제 해결 과정 (Troubleshooting)

문제:
전체 데이터 중 VIP 비율이 극히 낮아 모델이 모든 고객을 '일반'으로 예측하는 경향 발생.

해결책: 계층적 모델링 (2-Stage Modeling)
- Step 1: 노이즈(확실한 비가망 고객) 제거를 위한 1차 필터링.
- Step 2: 남은 후보군 내에서 정밀한 VIP 분류 모델 적용.

Metric 재정의:
단순 정확도(Accuracy)가 아닌, 실제 VIP를 놓치지 않는 재현율(Recall)과 
타겟팅 효율인 정밀도(Precision)의 조화평균(F1-score)을 최적화.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4. 핵심 성과 (Key Results)

성능 개선:
단일 모델 대비 정확도 34% -> 44%로 개선, 오차율 약 3배 감소.

비즈니스 기대 효과:
무작위 마케팅 대비 타겟팅 적중률 향상으로 마케팅 비용 절감 및 
VIP 전환율 증대 기대.
